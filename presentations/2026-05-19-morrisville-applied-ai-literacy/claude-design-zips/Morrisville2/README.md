# AI Literacy in Applied Contexts

**A talk by Steven M. Schneider**
SUNY Polytechnic Institute · AIX Center
Delivered at SUNY Morrisville Faculty Development · May 19, 2026

> *"When the AI tells you what to do."*

---

## What this repository is

This is the full source of a faculty-development talk on AI literacy in
applied fields — dairy, automotive, horticulture — together with the
prompt transcripts that produced it.

The talk itself argues that AI literacy in applied programs is not
primarily about using tools or producing content with AI. It is about
preserving independent professional judgment while AI systems
increasingly organize what appears important before humans even begin to
think. The repository is part of that argument: the only way to evaluate
a claim about AI-generated work is to be able to see the conversation
that produced it.

You are encouraged to zip this repository, upload it to a language
model, and ask it questions. That is the assignment.

## Provenance

### Talk text

One hundred percent of the talk content is AI-generated. The only
authorial contribution from Steven Schneider, in the conventional sense,
is the prompts.

The complete prompt transcripts of the conversations that produced the
talk are stored in [`conversations/`](./conversations/). They are
provided as Markdown exports so they can be diffed, searched, and
re-uploaded to any model for re-examination.

### Photographs

The three "stop" slides (dairy farm, auto shop, greenhouse) use images
generated by **Google Gemini**. The full image-generation conversation —
prompts, iterations, and final selections — is preserved in
[`Steve-Gemini-make-images-from-talk.md`](./Steve-Gemini-make-images-from-talk.md).

| Slide | File | Subject |
|------|------|---------|
| 04 — Dairy | `images/stop-dairy-2.webp` | Robotic milking parlor |
| 05 — Auto shop | `images/stop-auto.webp` | OBD-II diagnostic scan |
| 06 — Greenhouse | `images/stop-green.webp` | Sensored greenhouse |

The dropped photos are also embedded inside `.image-slots.state.json`
so the deck displays correctly even if the `images/` folder is
detached. When you replace a slide image by dragging a new one onto
the slot, the sidecar updates immediately; export a fresh standalone
file into `images/` if you want the originals to stay in sync.

### Slide design

The slide deck itself — layout, typography, color system, code — was
also AI-assisted. It was produced through conversation with Claude
(Anthropic) on Claude's design tool. No third-party design templates or
stock components are used.

## Quick start

The deck is a single self-contained HTML page. No build step, no server
required.

```bash
# clone
git clone <this-repo-url> morrisville-ai-literacy
cd morrisville-ai-literacy

# open
open "Morrisville Talk.html"     # macOS
xdg-open "Morrisville Talk.html" # Linux
start "Morrisville Talk.html"    # Windows
```

Or just double-click `Morrisville Talk.html` in your file manager.

**Controls**
- `→` / `←` or click — next / previous slide
- `S` — toggle speaker-notes view
- Browser print (`⌘P` / `Ctrl+P`) — one PDF page per slide
- Tweaks panel (bottom-right) — swap palettes live

The dropped photos are stored in `.image-slots.state.json`. The
high-resolution originals live in `images/`. If you want to swap them
out for your own, drag a new image onto any of the three stop slides
when viewing locally.

## Try the assignment yourself

The closing slide poses a question: *Can I get credit for this
assignment?*

To evaluate it, do what the speaker invites you to do:

1. Download or zip this entire repository.
2. Upload it to a language model of your choice.
3. Ask the model anything you want about how the talk was produced.

The conversations are the work.
