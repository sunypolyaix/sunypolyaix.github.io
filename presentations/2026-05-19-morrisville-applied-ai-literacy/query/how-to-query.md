# How to Query This Repository

This repository is designed to be uploaded to a language model. The transcripts, drafts, feedback, and README files together constitute the full intellectual record of how this talk was made.

---

## Step 1 — Get the files

**Option A: Download as zip**
- Go to the GitHub repository
- Click Code → Download ZIP
- Unzip locally

**Option B: Clone**
```
git clone https://github.com/stevesunypoly/tilde-steve.git
```
Navigate to `people/steve/talks~papers/2026-05-morrisville-applied-ai-literacy/`

---

## Step 2 — Upload to a model

**Claude:** Start a new conversation. Click the paperclip or attachment icon. Upload the zip file or individual .md files. Claude will index the contents.

**ChatGPT:** Same process. GPT-4o accepts zip files and multiple file uploads.

**NotebookLM:** Upload individual .md files as sources. NotebookLM is optimized for document corpora and works well for this use case.

---

## Step 3 — Starter prompts

Paste one of these to begin:

---

**Overview:**
```
You are a thinking partner on the attached repository of AI conversations. This repository contains the source transcripts, drafts, and supporting materials for a faculty development talk on AI literacy in applied contexts, delivered at SUNY Morrisville on May 19, 2026. Begin by summarizing what you find — the argument, the structure, and the evidence of how the work was made.
```

**The argument:**
```
What is the central argument of this talk? How did it develop across the conversations in this repository? Where did it change, and what caused it to change?
```

**Aviation literature:**
```
What did the author learn about aviation automation research in these conversations? Which specific failure modes are discussed, and how do they map to the pedagogical argument for applied programs?
```

**Prompt analysis:**
```
Look at the primary transcript (Morrisville/Farmingdale talks). Count the prompts and responses. What does the ratio of prompt length to response length suggest about how the work was done? What was the author's prior knowledge, and what was learned through the conversation?
```

**RTW demonstration:**
```
This repository is described as a demonstration of "reading, thinking, and writing using AI as cognitive infrastructure." Based on the transcripts, make the case that this is true — or challenge it.
```

**The credit question:**
```
The README asks: "Can I get credit for this assignment?" Based on everything in this repository, how would you answer that question? What does "credit" mean in the context of AI-assisted intellectual work?
```
