# NYHIMA Workshop Scenarios
## Reading and Writing with AI — June 7, 2026

All scenarios share the same structure. Every element is extractable by section name:
- `## situation` — context, 2–3 sentences
- `## source` — document to upload or paste into the model
- `## writing_prompt` — what to ask the first model
- `## validation_prompt` — what to paste into the second model
- `## reflection` — debrief question

## Workshop Sprint Workflow

Each sprint follows this cycle:

1. **Choose** a scenario from any bucket
2. **Upload or paste** the `source` into your first model
3. **Run** the `writing_prompt` — read and save the output
4. **Open a second model** (different from the first)
5. **Paste** the `validation_prompt` — then paste in the output from step 3
6. **Compare** — where do the models diverge?
7. **Reflect** using the `reflection` question

## Export & Reproducibility

To make your work reproducible:
- Save your outputs as you go (copy to a doc, download conversation)
- Note which model and which system prompt you used
- Your synthesis is your artifact — the record of your thinking plus the model's

Browser extensions for full conversation export:
- Chrome/Edge: search "ChatGPT Exporter" or "Claude Exporter"
- Exports as markdown or JSON
- Store in Google Drive, SharePoint, or GitHub
